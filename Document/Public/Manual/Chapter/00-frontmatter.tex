\begin{center}
{\sffamily\large\color{rmegray}Mutatus $\cdot$ Mesozoa $\cdot$ Eukaron (R.VII)}\\[10pt]
{\sffamily\large\color{rmegray}M7M01 (Eukaron) R4T1}\\[4pt]
{\sffamily\Large\bfseries\color{rmegray}Microkernel General-Purpose Real-Time Operating System (Rev. 4 Typ. 1)}\\[8pt]
{\rmfamily\color{rmemid}Technical Reference Manual}\\[12pt]
\end{center}

\begin{description}[leftmargin=0pt,labelindent=0pt,style=nextline,itemsep=8pt]
    \item[\textsf{\color{rmepurple}Minimal Yet Efficient Kernel}]
    The smallest possible kernel.
    The scheduler runs at user level.

    \item[\textsf{\color{rmepurple}Broad Architectural Support}]
    Supports symmetric or asymmetric multi-processor architectures.
    Supports uniform or non-uniform memory access architectures.
    All common hardware features are covered by kernel function calls.

    \item[\textsf{\color{rmepurple}Mature Capability Management}]
    A capability-based third-generation lockless microkernel.
    Genuine separation of kernel mode and user mode.

    \item[\textsf{\color{rmepurple}Flexible Memory Management}]
    Memory access is controlled through normal or path-compressed page tables.
    All memory mappings are managed at user level.

    \item[\textsf{\color{rmepurple}Advanced Thread and Process Model}]
    Threads can be transferred between multiple processors.
    Threads can migrate between multiple processes.
    Other operating systems can be hosted with full or para-virtualization.

    \item[\textsf{\color{rmepurple}Advanced Synchronous and Asynchronous Communication Mechanism}]
    Synchronous invocations are used for inter-process communication.
    Asynchronous signals are used to synchronize threads or handle interrupts.
\end{description}
